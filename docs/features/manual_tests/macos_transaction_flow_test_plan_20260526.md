## 1. 테스트 목적

macOS 앱에서 거래 입력 폼이 원장과 현재 포트폴리오 상태를 일관되게 갱신하는지 확인한다.

중점 확인 항목:

- 새 거래의 `포트폴리오 계산에 반영` 기본값이 켜져 있는지
- 보유 종목 수량, 평균단가, 결제 현금이 거래 유형별로 올바르게 변하는지
- 현금 계좌 입금, 출금, 이체, 환전이 잔액과 거래 내역에 올바르게 반영되는지
- 저장 후 상세 화면, 거래 탭, 서버 동기화 후 재조회에서 동일한 결과가 유지되는지

## 2. 현재 앱 기준 상태

Computer Use로 확인한 현재 화면:

- 앱은 자산 상세 화면에 진입해 있음
- `테스트 주식` 자산군에 보유 종목 4개 표시
- `테스트 주식 현금` 계좌가 표시되며 잔액은 `1,000,000원`
- 메모에 `테스트 계정 seed 데이터` 표시

원격 seed 검증 결과:

- 자산군: 3개
- 홀딩: 10개
- 각 홀딩 초기 매입가: `100,000원`
- 각 홀딩 초기 수량: `1`
- 자산군별 현금 계좌: 3개
- 각 현금 계좌 초기 잔액: `1,000,000원`

시장가 자동 갱신으로 상세 화면 평가금액은 `100,000원`과 다를 수 있다. 이 테스트에서는 평가금액보다 `수량`, `평균단가`, `현금 잔액`, `거래 내역`을 기준으로 판정한다.

## 3. 공통 준비

1. macOS 앱이 실행 중인지 확인한다.
2. 테스트 계정으로 로그인되어 있지 않으면 로그인한다.
3. 서버 코어 데이터 가져오기를 실행한다.
4. 포트폴리오 또는 자산 상세 화면에서 다음 기준값을 기록한다.
   - `테스트 주식 현금`: `1,000,000원`
   - `테스트 ETF/펀드 현금`: `1,000,000원`
   - `테스트 코인 현금`: `1,000,000원`
   - `삼성전자`: 수량 `1`, 평균단가 `100,000원`
5. 각 케이스 저장 직후 상세 화면을 새로고침하거나 뒤로 갔다가 다시 진입해 표시가 유지되는지 확인한다.

## 4. 매수 테스트

대상: `테스트 주식 > 삼성전자`

입력값:

- 거래 유형: `매수`
- 이름: `수동 테스트 매수`
- 단가: `100000`
- 수량: `1`
- 포트폴리오 계산에 반영: 켜짐

절차:

1. `삼성전자` 보유 상세로 진입한다.
2. 거래 추가 버튼을 누른다.
3. 거래 유형이 `매수`인지 확인한다.
4. `포트폴리오 계산에 반영` 스위치가 기본으로 켜져 있는지 확인한다.
5. 입력값을 저장한다.

기대 결과:

- 삼성전자 수량: `1 -> 2`
- 삼성전자 평균단가: `100,000원`
- `테스트 주식 현금`: `1,000,000원 -> 900,000원`
- 거래 내역에 `수동 테스트 매수`, `매수`, 거래금액 `100,000원`이 표시된다.
- 거래 탭에서 해당 거래 금액은 단가가 아니라 총액 `100,000원`으로 표시된다.

## 5. 매도 테스트

선행 조건: 4번 매수 테스트 완료 상태

입력값:

- 거래 유형: `매도`
- 이름: `수동 테스트 매도`
- 단가: `120000`
- 수량: `1`
- 포트폴리오 계산에 반영: 켜짐

절차:

1. `삼성전자` 보유 상세에서 거래 추가 버튼을 누른다.
2. 거래 유형을 `매도`로 변경한다.
3. 입력값을 저장한다.

기대 결과:

- 삼성전자 수량: `2 -> 1`
- 삼성전자 평균단가: `100,000원`
- `테스트 주식 현금`: `900,000원 -> 1,020,000원`
- 거래 내역에 `수동 테스트 매도`, `매도`, 거래금액 `120,000원`이 표시된다.
- 성과/원장 기준 실현손익은 `20,000원` 증가한다.

추가 음수 케이스:

- 현재 보유 수량보다 큰 수량으로 매도 저장을 시도한다.
- 기대 결과: 저장 실패 메시지가 표시되고 수량/현금 잔액은 변하지 않는다.

## 8. 이체 테스트

선행 조건: 7번 출금 테스트 완료 상태

대상:

- 출금 계좌: `테스트 주식 현금`
- 입금 계좌: `테스트 ETF/펀드 현금`

입력값:

- 거래 유형: `이체`
- 이름: `수동 테스트 이체`
- 금액: `200000`
- 포트폴리오 계산에 반영: 켜짐

절차:

1. `테스트 주식 현금` 상세 화면에서 거래 추가 버튼을 누른다.
2. 거래 유형을 `이체`로 변경한다.
3. 대상 계좌를 `테스트 ETF/펀드 현금`으로 선택한다.
4. 입력값을 저장한다.

기대 결과:

- `테스트 주식 현금`: `1,070,000원 -> 870,000원`
- `테스트 ETF/펀드 현금`: `1,000,000원 -> 1,200,000원`
- 두 계좌의 거래 내역에 같은 이체 이벤트가 표시된다.
- 전체 포트폴리오 총액은 이체 전후로 변하지 않는다.
- 거래 탭에서 이체 금액은 수익/손실 색상이 아닌 중립 색상으로 표시된다.

## 9. 환전 테스트

선행 조건: 8번 이체 테스트 완료 상태

대상:

- 출금 계좌: `테스트 주식 현금`
- 환전 방향: KRW -> USD

입력값:

- 거래 유형: `환전`
- 이름: `수동 테스트 환전`
- 원화 금액: `1300`
- 환율: `1300`
- 포트폴리오 계산에 반영: 켜짐

절차:

1. `테스트 주식 현금` 상세 화면에서 거래 추가 버튼을 누른다.
2. 거래 유형을 `환전`으로 변경한다.
3. 원화 금액과 환율을 입력한다.
4. 저장한다.

기대 결과:

- `테스트 주식 현금`: `870,000원 -> 868,700원`
- 같은 자산군에 USD 현금 계좌가 없으면 새 USD 현금 계좌가 생성된다.
- USD 현금 계좌 잔액은 `1 USD` 증가한다.
- 전체 포트폴리오 총액은 환율 환산 기준으로 큰 차이 없이 유지된다.
- 거래 탭에서 환전은 내부 거래로 표시되고 수익/손실 색상이 아닌 중립 색상으로 표시된다.

4. 위 기대 결과의 수량과 잔액이 유지되는지 확인한다.

최종 기대 누적값:
