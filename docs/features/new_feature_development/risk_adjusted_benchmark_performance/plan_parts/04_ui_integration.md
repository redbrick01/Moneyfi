# 04 UI Integration

## Purpose

기존 `투자성과 분석` 화면에 고급 성과 섹션을 추가합니다. 기존 금액 성과와 새 수익률 성과를 혼동하지 않게 분리해서 표시해야 합니다.

## Placement

권장 위치:

1. 기존 순 투자성과 요약
2. 기존 성과 구성
3. 신규 고급 성과 요약
4. 벤치마크 비교
5. 위험조정 지표

## Advanced Performance Summary

표시 항목:

| 항목 | 예시 |
| --- | --- |
| 입출금 보정 기간 수익률 | `+8.4%` |
| 벤치마크 | `S&P 500 +6.1%` |
| 초과수익률 | `+2.3%p` |
| 변동성 | `연 18.2%` |
| Sharpe Ratio | `0.82` |
| 최대 낙폭 | `-12.4%` |

각 지표에는 사용자가 의미를 바로 이해할 수 있도록 1-2줄의 짧은 설명을 함께 표시합니다.

| 항목 | 설명 예시 |
| --- | --- |
| 입출금 보정 기간 수익률 | 입금과 출금을 제외하고 투자 자체가 만든 기간 수익률입니다. |
| 벤치마크 | 같은 기간 비교 기준이 된 시장 지수의 수익률입니다. |
| 초과수익률 | 내 포트폴리오가 기준 시장보다 얼마나 더 높거나 낮았는지 보여줍니다. |
| 변동성 | 기간 중 수익률이 얼마나 크게 흔들렸는지 나타냅니다. |
| Sharpe Ratio | 변동성 대비 성과를 보는 지표입니다. 높을수록 같은 흔들림에서 더 나은 성과였다는 뜻입니다. |
| 최대 낙폭 | 기간 중 고점에서 가장 깊게 하락했던 비율입니다. |

해석 문구 예시:

```text
같은 기간 S&P 500보다 2.3%p 높았지만, 변동성도 더 컸어요.
```

## Rate Label Separation

기존 화면의 `매수 원금 대비` 수익률과 새 `입출금 보정 기간 수익률`은 다른 지표입니다.

| 라벨 | 의미 | 사용 위치 |
| --- | --- | --- |
| 매수 원금 대비 | 순 투자성과 / 기간 매수 원금 | 기존 순 투자성과 카드 |
| 입출금 보정 기간 수익률 | 일별 현금흐름 보정 수익률 누적 | 고급 성과 섹션 |

UI에서 두 값을 같은 `수익률`이라는 단독 라벨로 표시하지 않습니다.

## Data States

| 상태 | UI |
| --- | --- |
| 정상 | 모든 지표 표시 |
| 벤치마크 없음 | 벤치마크/초과수익률만 데이터 부족 |
| 일별 수익률 부족 | Sharpe/변동성/MDD 데이터 부족 |
| 60거래일 미만 | Sharpe 숨김 또는 데이터 부족 |
| 20거래일 미만 | 벤치마크 비교/변동성 데이터 부족 |
| 계산 실패 | 기존 금액 성과는 유지 |

## Copy Rules

사용자에게 오해를 줄 수 있는 표현은 피합니다.

사용:

- `시장 대비`
- `매수 원금 대비`
- `입출금 보정 기간 수익률`
- `변동성 대비 성과`
- `기간 중 최대 하락`
- `데이터 부족`

설명 문구 원칙:

- 지표명만 노출하지 않고 1-2줄 설명을 함께 둡니다.
- 계산식을 먼저 보여주기보다 사용자가 해석할 수 있는 의미를 먼저 보여줍니다.
- 설명은 투자 판단을 지시하지 않고, 수치가 무엇을 말하는지만 설명합니다.

피함:

- `좋은 투자`
- `매수 추천`
- `매도 필요`
- `위험 없음`

## Required Widget Tests

| 테스트 | 기대 |
| --- | --- |
| 정상 데이터 | 고급 성과 섹션 표시 |
| 벤치마크 없음 | 데이터 부족 표시 |
| 초과수익률 양수 | 양수 색상 |
| 초과수익률 음수 | 음수 색상 |
| 기존 성과 계산 실패 없음 | 기존 카드 유지 |
| 두 수익률 라벨 분리 | 매수 원금 대비와 입출금 보정 기간 수익률을 구분 표시 |
| 지표 설명 표시 | 각 고급 지표에 1-2줄 설명 표시 |
