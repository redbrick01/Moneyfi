# 01. IA And Copy Contract

상태: 완료

## Role

새 투자성과 페이지의 정보 순서, 섹션명, 화면 copy, 데이터 부족 문구를 확정한다.

이 단계는 사용자에게 보이는 의미 구조를 고정하는 단계다. 계산 또는 UI 구현은 하지 않는다.

## Dependency Note

원칙상 이 문서는 [00_audit_and_boundaries.md](00_audit_and_boundaries.md)의 Completion Gate 완료 후 확정한다.

현재는 별도 00 audit 산출물이 아직 없으므로 다음 기존 문서를 기준으로 01 계약을 먼저 확정한다.

- `redesign_plan_v2.md`
- `page_information_inventory.md`
- `investment_judgment_revision_plan.md`
- `redesign_plan_v1.md`

00 audit에서 이 계약을 막는 사실이 발견되면, 01을 임의로 확장하지 않고 `Change Request`로 기록한 뒤 이 문서를 개정한다.

## Scope

1. 최종 섹션 순서를 확정한다.
2. 각 섹션의 제목, caption, helper 문구를 확정한다.
3. `시장` 표현을 `참고 벤치마크` 기준으로 정리한다.
4. 매수 원금 대비 수익률과 입출금 보정 기간 수익률의 copy를 분리한다.
5. 비용 미배분, 월별 미실현 제외, 환율 fallback, 스냅샷 부족 문구를 확정한다.
6. 390dp 첫 화면 wireframe을 텍스트로 고정한다.

## Out Of Scope

- Flutter widget 작성
- view model 작성
- chart/bar 시각 구현
- DB/API 변경
- copy 외 디자인 세부값 결정
- 신규 계산식 또는 신규 데이터 모델 확정

## IA Contract

v2 화면은 `판단 -> 참고 비교 -> 원인 -> 검산 -> 상세 -> 위험 -> 기준` 순서를 따른다.

| 순서 | 확정 섹션명 | 사용자 질문 | 표시 핵심 | 기존 섹션 매핑 |
| --- | --- | --- | --- | --- |
| 1 | 기간 수익률 | 이 기간 투자는 잘됐나? | 입출금 보정 기간 수익률, 순 투자성과, 원금 대비 수익률 | 요약 카드 재작성 |
| 2 | 참고 벤치마크 | 참고 기준과 비교하면 어떤가? | S&P 500 대비 초과수익률, 내 수익률, S&P 500 수익률 | 시장 비교와 위험에서 benchmark 분리 |
| 3 | 성과 원인 | 무엇이 성과를 만들었나? | 가장 큰 플러스/마이너스 요인, 실현/미실현/수입/비용 | 성과 원인 강화 |
| 4 | 성과와 현금흐름 | 계좌 변화와 투자성과가 어떻게 이어지나? | 순 투자성과, 외부 입출금, 내부 이동, 결제 현금흐름, 검산 가능 상태 | 제외 현금흐름 재구성 |
| 5 | 월별 확정 성과 | 어느 달에 확정 성과가 났나? | 최근 12개월, 실현, 수입, 비용, 순 확정 성과 | 월별 실현성과 이름/범위 수정 |
| 6 | 종목별 기여도 | 어떤 종목이 기여했나? | 필터, 정렬, 총 성과, 기여율, 실현/미실현/수입 | 종목별 성과 유지+명확화 |
| 7 | 위험 해석 | 성과의 흔들림과 낙폭은 어땠나? | 변동성, Sharpe, 최대 낙폭, 데이터 부족 사유 | 시장 비교와 위험에서 risk 분리 |
| 8 | 데이터 기준 | 숫자는 어떤 기준으로 계산됐나? | 제외 항목, 비용 미배분, 월별 범위, 환율 기준, 스냅샷 기준 | 하단 부록성 안내 |

| 지표 | 화면 문구 | 의미 |

| 요소 | 확정 문구 |
| --- | --- |

| 비교 문구 | `S&P 500 대비 {value}` |

표현 규칙:

- `시장 비교`, `시장 대비`, `시장보다`를 쓰지 않는다.

- S&P 500을 모든 포트폴리오의 정답 기준처럼 표현하지 않는다.

## First-View Wireframe

390dp 모바일 기준 첫 화면은 아래 순서를 유지한다.

```text
투자성과 분석

[1개월] [3개월] [6개월] [올해] [전체]

기간 수익률
+4.2%
입출금 영향을 제외한 성과

순 투자성과 +420,000원
원금 대비 +3.8%

참고 벤치마크
S&P 500 대비 +1.2%p
내 수익률 +4.2% · S&P 500 +3.0%

성과 원인
이번 기간 성과는 미실현손익이 가장 크게 만들었습니다.
```

첫 화면에 반드시 들어와야 하는 정보:

1. 기간 선택
2. 기간 수익률 또는 기간 수익률 데이터 부족 상태
3. 순 투자성과
4. 원금 대비 수익률 또는 원금 대비 데이터 부족 상태
5. 참고 벤치마크 첫 줄
6. 성과 원인 섹션의 시작

## Non-Copy Decisions

copy만으로 확정할 수 없어 다음 phase에서 다룰 결정이다.

| 결정 | 담당 phase | 비고 |
| --- | --- | --- |
| 데이터 부족 사유를 enum으로 둘지 sealed state로 둘지 | 02 | copy table의 상태를 구현 모델로 매핑해야 한다. |
| 시작/종료 총자산 검산 가능 여부 | 00/02 | audit 결과에 따라 검산 또는 fallback으로 갈린다. |
| benchmark fetch 실패 상태를 서비스에서 어떻게 전달할지 | 02 | UI copy는 확정, state 전달 방식은 미정. |
| warning/info affordance에 아이콘을 쓸지 | 03/04/05 | 디자인 토큰/컴포넌트 기준에 맞춰 결정한다. |
| 데이터 기준 섹션을 accordion으로 둘지 static section으로 둘지 | 05/06 | 390dp 공간과 접근성 확인 후 결정한다. |
