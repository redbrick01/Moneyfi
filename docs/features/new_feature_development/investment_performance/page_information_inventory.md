# Investment Performance Page Information Inventory

이 문서는 `투자성과 분석` 페이지가 화면에 표시하는 정보와 각 정보의 계산 기준을 정리한다.

## Source

| 항목 | 위치 |
| --- | --- |
| 화면 구현 | `lib/pages/investment_performance_page.dart` |
| 진입 페이지 제목 | `투자성과 분석` |
| 기본 기간 | `올해` |
| 기간 프리셋 | `1개월`, `3개월`, `6개월`, `올해`, `전체` |
| 기본 벤치마크 | `S&P 500` (`SP500`) |

## Page Sections

페이지는 다음 순서로 정보를 표시한다.

| 순서 | 섹션 | 주요 목적 |
| --- | --- | --- |
| 1 | 요약 카드 | 선택 기간의 순 투자성과와 핵심 구성 요소를 빠르게 보여준다. |
| 2 | 성과 원인 | 실현, 미실현, 수입, 비용이 전체 성과에 얼마나 기여했는지 분해한다. |
| 3 | 시장 비교와 위험 | 입출금 보정 수익률, 벤치마크, 위험 지표를 보여준다. |
| 4 | 월별 실현성과 | 월별 순 실현성과 추이와 구성 요소를 보여준다. |
| 5 | 종목별 성과 | 보유 종목별 성과와 기여도를 보여준다. |
| 6 | 제외 현금흐름 | 투자성과 계산에서 제외한 외부/내부 현금흐름을 별도로 보여준다. |

## Summary Card

상단 요약 카드에는 다음 정보가 표시된다.

| 표시명 | 내용 | 계산/출처 |
| --- | --- | --- |
| 기간 선택 | `1개월`, `3개월`, `6개월`, `올해`, `전체` | 선택 기간을 `from`, `to`로 변환해 모든 집계에 전달한다. |
| 순 투자성과 | 선택 기간의 최종 투자성과 | `순 실현성과 + 미실현손익` |
| 매수 원금 대비 수익률 | 순 투자성과를 매수 원금으로 나눈 값 | `순 투자성과 / 매수 원금 * 100` |
| 벤치마크 비교 배지 | S&P 500 대비 초과수익률 또는 데이터 부족 문구 | `포트폴리오 기간 수익률 - S&P 500 기간 수익률` |
| 기준 문구 | `입출금과 내부 이동 제외 기준` | 투자성과 계산에서 현금흐름을 제외한다는 안내 |
| 순 실현 | 확정된 순 실현성과 | `실현손익 + 배당/이자 - 수수료 - 세금` |
| 미실현 | 선택 기간 미실현손익 변화 | `현재 미실현손익 - 기간 시작 전 스냅샷 미실현손익` |
| 배당/이자 | 선택 기간 수입 | `dividend`, `interest` 원장 라인 집계 |
| 비용 | 선택 기간 비용 | `-(수수료 + 세금)` |

## Performance Attribution

`성과 원인` 섹션은 다음 항목을 금액, 전체 대비 기여율, 막대 길이로 표시한다.

| 표시명 | 부호 | 계산/출처 |
| --- | --- | --- |
| 실현손익 | 손익 방향 그대로 | `realized_pnl` 합계 |
| 미실현손익 | 손익 방향 그대로 | 보유 종목별 기간 미실현손익 합계 |
| 배당/이자 | 양수 수입 | `dividend`, `interest`의 `gross_amount` 또는 `cash_delta` 절대값 |
| 수수료 | 비용이므로 음수 표시 | `fee`의 `cash_delta` 또는 `gross_amount` 절대값에 `-` 적용 |
| 세금 | 비용이므로 음수 표시 | `tax`의 `cash_delta` 또는 `gross_amount` 절대값에 `-` 적용 |

하단에는 다음 요약 행이 추가로 표시된다.

| 표시명 | 계산/출처 |
| --- | --- |
| 순 투자성과 | `순 실현성과 + 미실현손익` |
| 순 실현성과 | `실현손익 + 배당/이자 - 수수료 - 세금` |
| 매수 원금 | `buy` 원장 라인의 `gross_amount` 합계 |
| 매도 회수금 | `sell` 원장 라인의 `gross_amount` 합계 |

기여율은 `항목 금액 / 순 투자성과 * 100`으로 표시한다. 분모가 0에 가까우면 기여율을 생략한다.

## Market And Risk

`시장 비교와 위험` 섹션은 고급 성과 지표를 표시한다.

| 표시명 | 보조 문구 | 계산/출처 |
| --- | --- | --- |
| 기간 수익률 | `입출금 보정` | 포트폴리오 일별 수익률을 누적 복리로 계산 |
| S&P 500 | `선택 기간` | 벤치마크 시작/종료 가격으로 계산한 기간 수익률 |
| 초과수익률 | `시장 대비` | `기간 수익률 - S&P 500 수익률` |
| 변동성 | `연율화` | 일별 수익률 표본 표준편차를 연율화 |
| Sharpe | `위험 대비 성과` | `(연율화 수익률 - 무위험수익률) / 연율화 변동성` |
| 최대 낙폭 | `고점 대비` | 포트폴리오 평가액 시계열의 최대 drawdown |

금리 데이터가 있으면 `미국 13주 T-Bill {date} 기준 Sharpe Ratio입니다.`를 표시한다. 금리 데이터를 가져오지 못하면 `금리 데이터를 가져오지 못해 0% 기준으로 Sharpe Ratio를 계산했습니다.`를 표시한다.

데이터가 부족한 지표는 `데이터 부족`으로 표시한다.

## Monthly Realized Performance

`월별 실현성과` 섹션은 최근 최대 12개월을 표시한다.

| 표시명 | 내용 |
| --- | --- |
| 헤더 보조 문구 | `최근 {개월 수}개월` |
| 막대 차트 | 월별 순 실현성과의 절대값을 최대값 대비 비율로 표시 |
| 월 | `YYYY-MM` |
| 실현 | 해당 월의 실현손익 |
| 수입 | 해당 월의 배당/이자 |
| 비용 | 해당 월의 `-(수수료 + 세금)` |
| 우측 금액 | 해당 월의 순 실현성과 |

월별 순 실현성과 계산식은 `실현손익 + 배당/이자 - 수수료 - 세금`이다.

집계 대상 원장 액션은 `sell`, `dividend`, `interest`, `fee`, `tax`이다. 데이터가 없으면 `월별로 집계할 실현 손익이 아직 없습니다.`를 표시한다.

## Holding Contribution

`종목별 성과` 섹션은 투자 대상 보유 종목별 성과를 표시한다.

### Filters

| 필터 | 조건 |
| --- | --- |
| 전체 | 모든 표시 대상 종목 |
| 실현 | 실현손익 절대값이 0보다 큰 종목 |
| 손실 | 총 성과가 0보다 작은 종목 |
| 수입 | 배당/이자 수입 절대값이 0보다 큰 종목 |

### Sorting

| 정렬 | 기준 |
| --- | --- |
| 총 성과 | 총 성과 내림차순 |
| 손실 | 총 성과 오름차순 |
| 실현 | 실현손익 내림차순 |
| 미실현 | 미실현손익 내림차순 |
| 배당/이자 | 수입 내림차순 |

### Row Fields

| 표시명 | 내용/계산 |
| --- | --- |
| 종목명 | `HoldingItem.name` |
| 보조 정보 | `자산명 · 심볼 · 통화코드` |
| 총 성과 | `실현손익 + 미실현손익 + 수입` |
| 기여율 | `종목 총 성과 / 전체 순 투자성과 * 100` |
| 실현 | 종목별 `realized_pnl` |
| 미실현 | `현재 미실현손익 - 기간 시작 전 스냅샷 미실현손익` |
| 수입 | 종목별 배당/이자 |

표시 대상에서 숨김 자산, 숨김 종목, 현금 자산/종목은 제외한다. 원장 성과가 없는 종료 투자 포지션도 제외한다.

빈 상태 문구는 다음과 같다.

| 상황 | 문구 |
| --- | --- |
| 종목 데이터 없음 | `분석할 투자 거래가 아직 없습니다.` |
| 실현 필터 결과 없음 | `실현손익이 발생한 매도 거래가 아직 없습니다.` |
| 손실 필터 결과 없음 | `손실이 발생한 종목이 없습니다.` |
| 수입 필터 결과 없음 | `배당이나 이자가 발생한 종목이 없습니다.` |

## Excluded Cash Flows

`제외 현금흐름` 섹션은 순 투자성과에 포함하지 않는 현금흐름을 별도로 보여준다.

| 표시명 | 계산/출처 |
| --- | --- |
| 외부 입금 | `deposit`, `opening_cash`의 `cash_delta` 절대값 합계 |
| 외부 출금 | `withdrawal`의 `cash_delta` 절대값 합계에 `-` 적용 |
| 외부 입출금 합계 | `deposit`, `withdrawal`, `opening_cash`의 `cash_delta` 합계 |
| 투자 결제 현금흐름 | `settlement`의 `cash_delta` 합계 |
| 내부 이동 | `transfer_out`, `transfer_in`, `fx_out`, `fx_in`의 `cash_delta` 절대값 합계 |

## Data Loading And Currency

페이지는 선택 기간 기준으로 다음 데이터를 불러온다.

| 데이터 | 용도 |
| --- | --- |
| `fetchAssets()` | 표시 대상 자산/종목 목록 |
| `fetchLedgerHoldingPerformanceByHoldingId(from, to)` | 종목별 실현손익, 수입, 매수/매도 금액 |
| `fetchLedgerPortfolioPerformanceByCurrency(from, to)` | 전체 포트폴리오 성과와 제외 현금흐름 |
| `fetchLedgerMonthlyPerformanceByCurrency(from, to)` | 월별 실현성과 |
| `fetchLatestExchangeRate()` | USD 원장 집계의 KRW 환산 |
| `fetchPreviousPortfolioSnapshot(from)` | 기간 시작 전 미실현손익 기준점 |
| `fetchPortfolioSnapshotHoldingItemsByDates()` | 시작 전 스냅샷의 종목별 미실현손익 |
| `rebuildPortfolioDailyReturns(from, to)` | 일별 수익률 파생 데이터 재계산 |
| `fetchPortfolioDailyReturns(from, to)` | 기간 수익률, 변동성, Sharpe, 최대 낙폭 계산 |
| `ensureBenchmarkPrices()` | S&P 500 가격 캐시 확보 |
| `ensureRiskFreeRates()` | 미국 13주 T-Bill 금리 캐시 확보 |
| `compareBenchmarkPeriodReturn()` | 벤치마크 기간 수익률과 초과수익률 |

KRW가 아닌 USD 금액은 최신 환율로 KRW 환산한다. 최신 환율이 없으면 `1.0`을 사용한다.

## Core Formulas

```text
순 실현성과 = 실현손익 + 배당/이자 - 수수료 - 세금
순 투자성과 = 순 실현성과 + 미실현손익
매수 원금 대비 수익률 = 성과금액 / 매수 원금 * 100
종목 총 성과 = 실현손익 + 미실현손익 + 수입
기여율 = 항목 금액 / 기준 성과 * 100
기간 미실현손익 = 현재 미실현손익 - 기간 시작 전 스냅샷 미실현손익
초과수익률 = 포트폴리오 기간 수익률 - S&P 500 기간 수익률
```

매수 원금 또는 기여율 분모가 0에 가까우면 해당 비율은 표시하지 않는다.
