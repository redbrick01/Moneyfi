## Snapshot Calculation Changes

Updated:

- `supabase/functions/create-portfolio-snapshot/index.ts`
- `supabase/migrations/20260524093000_fix_cash_snapshot_profit.sql`
- `supabase/migrations/20260524094000_recalculate_snapshot_totals_after_cash_fix.sql`
- `docs/data_and_sync.md`
- `docs/features/bug_fixes/cash_snapshot_profit_fix/test_report_20260524.md`

Rules now documented in `docs/data_and_sync.md#snapshot-calculation-rules`:

- Hidden assets are excluded from snapshot generation.
- Hidden holdings are excluded.
- Zero-quantity holdings are excluded.
- Hidden cash accounts are excluded.
- If an asset has child rows but all are excluded, it does not fall back to
  `asset.value`.
- Snapshot header totals are recalculated from snapshot item totals.
- Cash contributes to total assets but never creates valuation profit.

Cash formula:

```text
cash valuationAmount = KRW-converted balance
cash purchaseAmount = KRW-converted balance
cash profitAmount = 0
cash profitRate = 0
```
