## Maintenance Rules

- 새 문서를 추가하면 이 인덱스에 링크를 함께 추가합니다.
- 실행 가능한 절차는 명령어 블록을 포함합니다.
- 키, 토큰, 개인 계정 정보는 문서에 직접 적지 않습니다.
- 오래된 설계 문서는 삭제보다 `Archived` 섹션을 추가해 맥락을 남깁니다.
